# ワンビーコミュニティ — デモサイト

デザインコミュニティ「ワンビーコミュニティ」の1ページ構成のデモサイトです。HTML、CSS、JavaScriptのみで動作します。`index.html` をブラウザーで開くと確認できます。

## 内容

- レスポンシブ対応のランディングページ
- ご指定のデザイン画像に合わせた、写真主導のヒーロー、3列の紹介帯、3枚の学びのカード、Founder Story、最終案内
- 参加案内のデモダイアログ
- 人物写真はすべて本デモ用に生成したイメージ
- 見出しに Noto Serif JP、本文と UI に Noto Sans JP を使用。手書き書体は使用していません。

## 公開前に必要な差し替え

- マスヤさん本人の紹介文と、掲載したい場合は本人の写真
- 実際の活動内容、開催日程、参加費
- 申込先または問い合わせ先。現状の参加ボタンはデモ案内のみ表示します。

掲載文中の経歴・実績は創作していません。Founder Storyはデモ用の文章です。

## ファイル

- `index.html` — ページ本文
- `styles.css` — デザインとレスポンシブ設定
- `script.js` — メニューとデモダイアログ
- `assets/` — 生成した写真6点

## ライセンスについて

本デモの画像・文章を外部で利用する場合は、利用先の方針に合わせて確認してください。
